# CodeBot AI Studio

Welcome to **CodeBot AI Studio**! This is a custom web application designed to generate pure HTML and CSS code blocks, provide real-time code execution, and translate speech into markup using voice commands.

## Key Features
* **AI Gen:** Instant smart code layout generation.
* **Mic Mode:** Voice-activated coding commands.
* **Explainer:** Analytical logic breakdown for scripts.
* **Live Preview:** Instant browser rendering engine.
