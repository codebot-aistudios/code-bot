# Code Bot

Code Bot is an AI-powered web code generator that creates HTML, CSS, and JavaScript from simple text prompts.

## Features

- Generate HTML, CSS, and JavaScript
- Simple and responsive interface
- Fast code generation
- Copy generated code with one click
- Easy to use

## How to Use

1. Enter what you want to build.
2. Click **Generate Code Source**.
3. Wait for the generated code.
4. Copy the HTML, CSS, or JavaScript.
5. Use the code in your project.

## Technologies Used

- HTML5
- CSS3
- JavaScript
